一个现代化的桌面应用，用于将 DTS 音轨批量转换为 AC3 格式，解决某些电视（如 LG）不支持 DTS 音轨的问题。

## 📸 界面预览

华丽的现代深色主题界面，支持批量处理多个视频文件。

## 🎯 核心特性

### 🎬 批量处理
- **多文件选择** - 一次可选择多个视频文件进行批量转换
- **队列处理** - 自动按顺序处理所有文件
- **独立配置** - 每个文件可单独设置输出路径

### 🎨 现代界面
- **深色主题** - 精心设计的现代深色界面
- **实时进度** - 显示每个文件的转换进度
- **状态追踪** - 清晰标识等待/转换中/成功/失败状态
- **流畅动画** - 丰富的悬停和过渡效果

### ⚡ 高效转换
- **智能命名** - 自动移除文件名中的 DTS 标识
- **质量保证** - 视频流直接复制，保持原始质量
- **音质可选** - 支持 448k/640k/768k 三种比特率
- **字幕保留** - 自动保留原视频的字幕轨道

### 🔧 便携易用
- **开箱即用** - 无需安装，下载即可运行
- **完全独立** - 内置 FFmpeg，无需额外依赖
- **轻松迁移** - 单个 exe 文件，可复制到任何电脑

## 📥 下载安装

### 方式一：直接下载（推荐）

前往 [Releases](../../releases) 页面下载最新版本的 `DTS转AC3工具.exe`

- 文件大小：约 112 MB
- 支持系统：Windows 10/11 (64位)
- 无需安装：下载后直接双击运行

### 方式二：从源码构建

需要 Node.js 18+ 环境

```bash
# 克隆仓库
git clone https://github.com/你的用户名/DTS-to-AC3-Converter.git
cd DTS-to-AC3-Converter

# 安装依赖
npm install

# 运行开发模式
npm run dev

# 构建可执行文件
npm run build:win
```

构建完成后，可执行文件位于 `release` 文件夹。

## 🚀 使用指南

### 基本使用

1. **启动程序** - 双击 `DTS转AC3工具.exe`
2. **添加文件** - 点击"添加文件"按钮，选择一个或多个带 DTS 音轨的视频文件
3. **查看列表** - 程序会列出所有文件，并自动生成输出路径
4. **修改路径**（可选）- 点击每个文件右侧的编辑按钮，可自定义输出路径
5. **选择音质** - 在"音频比特率"下拉菜单中选择（推荐 640k）
6. **开始转换** - 点击"开始批量转换"按钮
7. **等待完成** - 查看实时进度和统计数据

### 文件管理

- **移除文件** - 点击文件右侧的 ❌ 按钮可从列表中移除
- **编辑路径** - 点击 ✏️ 按钮可修改输出文件的保存位置和文件名
- **状态图标**：
  - ⏳ 灰色 - 等待转换
  - 🔄 蓝色旋转 - 正在转换
  - ✅ 绿色 - 转换成功
  - ❌ 红色 - 转换失败

### 音质选择

| 比特率 | 音质 | 文件大小 | 推荐场景 |
|--------|------|----------|----------|
| 448k | 标准 | 较小 | 普通观看 |
| 640k | 高质量 | 中等 | **推荐选择** |
| 768k | 超高质量 | 较大 | 影音发烧友 |

## ❓ 常见问题

### 为什么需要这个工具？

某些电视品牌（如 LG）不支持 DTS 音轨播放，导致下载的高清视频无声。此工具将 DTS 音轨转换为 AC3 格式，解决兼容性问题。

### 转换会损失画质吗？

不会。视频流直接复制（copy），不会重新编码，完全保持原始画质。仅转换音频轨道。

### 转换需要多长时间？

转换速度取决于：
- 视频时长
- 电脑性能
- 音频比特率

通常一部 2 小时的电影需要 5-15 分钟。

### 转换失败怎么办？

1. 检查输入文件是否完整，未损坏
2. 确保输出路径有写入权限
3. 尝试更换输出路径或文件名
4. 查看错误提示信息

### 支持哪些视频格式？

支持主流视频格式：
- MP4
- MKV
- AVI
- MOV
- M4V
